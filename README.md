# Python - Zadania i Ćwiczenia

Repozytorium zawiera kody źródłowe oraz rozwiązania zadań z kursu programowania w języku Python. Wszystkie skrypty i materiały powstają w ramach zajęć laboratoryjnych.

## Struktura repozytorium
Katalogi są podzielone na poszczególne zestawy zadań realizowane w trakcie semestru:

- **Zestaw_1/** - Wprowadzenie do środowiska Python (sesja interaktywna, podstawowe skrypty, prawa wykonywania plików w systemie Linux).
- **Zestaw_2/** - Operacje na łańcuchach znaków i listach (zadania 2.10 - 2.19) z wykorzystaniem pętli oraz podstawowych metod i funkcji wbudowanych.
- **Zestaw_3/** - Instrukcje warunkowe, pętle (for, while) oraz operacje na strukturach danych: list, tuple, set i dict (zadania 3.1 - 3.10).

## Środowisko pracy
- **Język:** Python 3.14.4
- **System operacyjny:** Ubuntu 26.04.1 LTS
- **Narzędzia:** Terminal, nano, Visual Studio Code
